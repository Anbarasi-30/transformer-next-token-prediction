# Transformer-Based Next-Token Prediction

## Project Description
This project demonstrates next-token prediction using a small Transformer model built with TensorFlow and Keras. It uses basic causal self-attention to learn relationships between tokens in a text sequence.

## Objectives
- Understand tokenization and vocabulary creation.
- Prepare input sequences and next-token targets.
- Implement positional embeddings.
- Build a Transformer block using causal self-attention.
- Train and evaluate a next-token prediction model.

## Technologies Used
- Python
- TensorFlow and Keras
- NumPy
- Matplotlib
- Google Colab

## Model Architecture
1. Token embedding
2. Positional embedding
3. Multi-head causal self-attention
4. Feed-forward network
5. Layer normalization and residual connections
6. Output layer for next-token prediction

## Dataset
A small, custom text dataset is used for demonstration and educational purposes.

## How to Run
1. Open the notebook in Google Colab.
2. Run the cells in order.
3. Train the model.
4. Review the training graph and sample predictions.

## Limitations
This project uses a small dataset and is intended for learning. Its predictions are not comparable to those of large language models.
